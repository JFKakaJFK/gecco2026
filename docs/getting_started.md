## Project Structure

In this section, the project structure is described, giving information on where to find what.

  - build/: autogenerated folder containing binaries, build cache & artefacts generated by C++ tests
  - cmake: CMake helper scripts - see working with CMake
  - docs: Documentation for contributors
  - examples/python: Python usage examples
  - examples/C++: C++ usage examples (non-existent)
  - extern/: vendored C++ dependencies
  - lib
    - docs: C++ documentation
    - include: C++ header definitions
      - goblin.h: main header file, currently maintained manually
    - src: C++ implementation files
    - tests: C++ tests
    - CMakeLists.txt: defines library, documentation and test build targets
  - pylib
    - include: autogenerated library interface
    - nanobind: autogenerated python bindings
    - pygom: the Python library
      - gp: genetic programming specific python code
      - __init__.py: entrypoint, makes the C++ symbols available, also nested namespaces
      - __init__.pyi: autogenerated, contains python interface and typing info (stubs file)
  - .clang-format: defines C++ auto-formatting style
  - .gitignore: defines which files not to commit to version control
  - CMakeLists.txt: root cmake project, sets up incremental compilation, locates dependencies (including the library), and defines the python library build target
  - Makefile: contains useful scripts
  - pyproject.toml: defines the Python package and its dependencies
